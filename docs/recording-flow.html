Four processes deep

That first hop looks like one arrow, but the click has to climb out through four separate programs before any C# of yours runs. Every rung is a real thing in your build output.

  1. your C# code
  2. Microsoft.Playwright.dllin your process · 1 MB · the API you call
  3. node.exeseparate process, spawned by your app · 92 MB
  4. Chromiumseparate process, spawned by node
  5. the pagewhere recorder.js and __pwsEmit live

your C# code
  └─ Microsoft.Playwright.dll     in your process

            └─ Chromium           separate process, spawned by node
                 └─ the page      where recorder.js and __pwsEmit live
Playwright's pipe — four processes deep, which is why a plain function call cannot do it and a binding has to exist.
Blazor's pipe — ordinary Blazor Server. Nothing to do with Playwright; it is only keeping the page you are looking at up to date.
